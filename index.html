MENSAJE DE SECRETARÍA GENERAL

Es un honor darles la bienvenida a ENCIMUN. Este encuentro representa una oportunidad para trascender el ámbito académico, conocer distintas perspectivas y asumir el compromiso que implica formar parte de un espacio de diálogo y representación internacional.

Ser delegado exige preparación, pensamiento crítico, capacidad de negociación y, sobre todo, la disposición de escuchar y comprender realidades distintas. Cada postura defendida, cada debate y cada acuerdo representan una oportunidad para demostrar que las diferencias no son un obstáculo, sino el punto de partida para construir soluciones.

Desde Secretaría General, los invitamos a asumir este desafío con responsabilidad, determinación y respeto. Aprovechen cada momento, cuestionen sus propias ideas y no pierdan de vista el propósito que nos reúne: hacer del diálogo una herramienta para construir un mejor futuro.

Les deseamos una experiencia llena de aprendizaje, grandes debates y logros que trasciendan estas jornadas.

Con nuestros mejores deseos,

SECRETARÍA GENERAL
